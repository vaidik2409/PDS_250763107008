# Introduction to Applied Data Science with Python

This repository contains my work from the **Introduction to Applied Data Science with Python** course by Simplilearn.

## Course Modules

| # | Module | Notebook |
|---|--------|----------|
| 1 | Python Basics | [01_Python_Basics.ipynb](01_Python_Basics.ipynb) |
| 2 | NumPy and Pandas | [02_Numpy_Pandas.ipynb](02_Numpy_Pandas.ipynb) |

| 4 | Machine Learning | [04_Machine_Learning.ipynb](04_Machine_Learning.ipynb) |

## Topics Covered

### 1. Python Basics
- Variables and data types
- Operators (arithmetic, comparison, logical)
- Strings
- Data structures (list, tuple, set, dictionary)
- Control flow (if-else, for, while)
- Functions and lambda
- List comprehension
- Exception handling

### 2. NumPy and Pandas
- NumPy arrays and operations
- Matrix creation and slicing
- Random numbers and statistics
- Pandas Series and DataFrame
- Filtering, sorting, grouping
- Handling missing values
- Exporting to CSV

### 3. Data Visualization
- Matplotlib (line, bar, scatter, histogram, pie, box)
- Seaborn (line, bar, scatter, histogram)
- Correlation matrix and heatmap
- Pair plot
- Data analysis

### 4. Machine Learning
- Linear Regression
- Train-test split
- Model training and prediction
- Model evaluation (MAE, MSE, R2)
- Multiple predictions
- Pass/Fail classification

## Requirements
